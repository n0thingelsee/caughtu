# caughtu
###### *(git and python3 required for download)*

Bash (Termux, Arch, etc...):
- `git clone https://github.com/n0thingelsee/caughtu.git`
- `cd caughtu`
- `python3 -m pip install -r requirements.txt`
- `python3 caughtu.py`

Windows:
- `cd C:\Users\%username%\Desktop`
- `git clone https://github.com/n0thingelsee/caughtu.git`
- `cd caughtu`
- `python -m pip install -r requirements.txt`
- `python caughtu.py`

I hope you like it
